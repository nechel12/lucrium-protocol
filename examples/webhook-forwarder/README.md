# Webhook-форвардер

Отправляет события площадок во внешний HTTP-endpoint. Полезен для интеграций
с CRM, Telegram-ботами и аналитикой без написания отдельного плагина.

Тело запроса:

```json
{
  "platform": "funpay",
  "session_id": "acc-1",
  "kind": "message",
  "ts": "2026-01-15T12:00:00Z",
  "payload": {"message": {"text": "Здравствуйте!"}}
}
```

## Настройки

| Ключ | Тип | По умолчанию | Назначение |
|---|---|---|---|
| `url` | string (uri) | — | куда отправлять POST |
| `secret` | string | `""` | значение заголовка `X-Lucrium-Secret` |
| `kinds` | array | `[]` (все) | фильтр по типам событий |
| `timeout_seconds` | number | `10` | таймаут запроса |

## Что демонстрирует

- `ctx.http` — прямой HTTP из плагина (требует `permissions.network = true`);
- `ctx.config` / `ctx.log`.

Ответ не-2xx логируется как предупреждение и не роняет плагин. Ретраев нет —
надёжную доставку должен обеспечивать принимающий сервис.
